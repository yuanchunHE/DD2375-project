# DD2375-project

This is a Python implementation of the polar-based quantum computer simulator for DD2375 the Project course at KTH.

---

## Description of Files
- **`DD2375_PolarQCSimulator.ipynb`**:  
  All implementation details include visualization tools for quantum states, performance comparison code, and experiment results.

- **`PolarQuantumSimulator.py`**:  
  Encapsulated quantum computer simulator for direct import and use.
  
- **`requirement.txt`**:  
  List of requirements for the simulator.

- **`test.py`**:  
  Circuit examples, including QFT and Grover's.

---

## Quick start

### Clone
```bash
git clone https://github.com/yuanchunHE/DD2375-project
cd DD2375-project
```

### Install Dependencies
```bash
pip install -r requirement.txt
```

### Run Examples

* Example in _.py_ file
Run the provided example file to see QFT and Grover's algorithm in action:
```bash
python test.py
```

* Example in _.ipynb_ file
See examples in the section **circuit examples** in the **Encapsulation**.
